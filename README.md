# Game Mass Translator

[English](README.en.md)

Game Mass Translator 是一套 Windows 遊戲翻譯工具，讓你把不同遊戲來源整理成專案，在同一個地方翻譯、檢查並安裝譯文。

目前版本：**1.6.9**。[下載最新版本](https://github.com/johnex2x/Game-Mass-Translator/releases)

![Game Mass Translator 主畫面與翻譯審核表格](assets/02-project-review.jpg)

## 特色

- 支援 Ren'Py、Unity、Translator++ 與 MTool 等多種遊戲來源。
- 可選擇手動網頁、CLI 或 Agent 翻譯方式。
- 翻譯後可用 V/X/I 審核，再安裝到遊戲中測試。

## 四步快速開始

1. 從[官方 Releases](https://github.com/johnex2x/Game-Mass-Translator/releases)下載 ZIP，解壓縮後執行 `Game Mass Translator 1.6.9.exe`。
2. 按主畫面的「從遊戲建立專案」大圖示，選擇遊戲資料夾並建立 `.rpytrans` 專案。
3. 按「網頁批次翻譯」大圖示，將批次交給你選擇的網頁 AI，再把完整結果貼回工具。
4. 檢查譯文並標記 V，按「安裝到遊戲」大圖示，然後進入遊戲確認翻譯。

## 支援來源

- Ren'Py
- Unity / XUnity.AutoTranslator / Naninovel / Mono
- Translator++ `.trans`
- MTool JSON
