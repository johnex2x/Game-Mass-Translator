# 安全回報 / Security Reporting

## 繁體中文

請不要在公開 Issue 張貼可利用的安全漏洞、遊戲本體、未公開遊戲內容、私人專案、API 金鑰或完整敏感 log。

請使用此 GitHub Repository 的 **Private vulnerability reporting** 提交安全問題。若該功能暫時不可用，請先在 Issue 只留下「需要私人安全聯絡」的非敏感訊息，不要描述利用步驟。

回報請包含：受影響版本、Windows 版本、最小重現步驟、預期與實際結果，以及可安全分享的修補建議。收到後會先確認重現性與影響範圍，再決定修補與公告時間。

## English

Do not post exploitable vulnerabilities, game files, unreleased game content, private projects, API keys, or complete sensitive logs in a public Issue.

Use this GitHub repository's **Private vulnerability reporting** feature for security reports. If it is temporarily unavailable, open only a non-sensitive Issue saying that a private security contact is needed; do not include exploit steps.

Include the affected version, Windows version, minimal reproduction steps, expected and actual results, and any safely shareable mitigation. Reports will be triaged for reproducibility and impact before a fix and disclosure timeline are chosen.
