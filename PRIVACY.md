# 隱私說明 / Privacy

## 繁體中文

Game Mass Translator 沒有帳號、廣告或遙測，也不會把你的專案傳送給本專案維護者。

使用網頁、CLI 或 Agent 翻譯時，所選遊戲文字、批次提示設定與命中術語會交給你選擇的外部服務；完整專案與遊戲檔案不會送出。資料如何保存與使用，以該服務的政策為準。

部分 Unity 功能需要下載必要元件。工具只會在你確認後開始下載。

## English

Game Mass Translator has no account system, advertising, or telemetry, and it does not send your project to the project maintainer.

When you use web, CLI, or Agent translation, the selected game text, batch prompt settings, and matching glossary terms are sent to the external service you choose; the complete project and game files are not sent. That service's own policies govern how the data is stored and used.

Some Unity features need additional components. The tool starts those downloads only after your confirmation.
